# Single Mode

Use single mode when the user names one paper or clearly wants one note.

Expected output:

- one detailed Markdown note in `论文笔记/Papers/`

Hard gate before reading or writing:

- run workspace preflight first
- if the research profile is missing, stop and ask the user for research domain information first
- save the answer before resuming note generation

Minimum sections:

- metadata
- abstract
- problem
- method
- key findings
- limitations
- relevance to my research
- follow-up actions

If the item has no fulltext, generate the note from metadata, abstract, notes, and annotations, and mark missing evidence explicitly.
