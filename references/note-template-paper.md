# Paper Note Template

Use the full paper template when the user asks for deep reading.

Frontmatter must be analytical rather than copied metadata. Read `frontmatter-rules.md` before filling:

- `theme`
- `study_area`
- `data_source`
- `methodology`
- `core_variable`
- `key_finding`
- `relevance`

Each of the fields above should be one short sentence and must be extracted, not pasted.

Core sections:

- frontmatter with Zotero identifiers
- 基本信息
- 摘要
- 核心问题
- 方法与技术路线
- 实验设计与结果
- 主要贡献
- 局限性与不足
- 当前研究画像
- 与我课题的关联度
- 与我的研究关系
- Zotero 笔记与批注
- 后续行动
