# Synthesis Mode

Use synthesis mode when the user wants cross-paper understanding rather than one note per paper.

Hard gate before reading:

- run workspace preflight first
- if the research profile is missing, stop before collecting papers for synthesis

Expected output:

- one synthesis note in `论文笔记/Synthesis/`

The synthesis should compare:

- what problem each paper targets
- what method family it uses
- what data or setting it evaluates on
- what strengths recur
- what limitations recur
- what gaps are still open

Include a compact included-papers table so the note remains traceable to the original sources.
